# 阿瓦隆网页版｜小红书游戏实录轮播图

共 7 张，统一为 3:4 竖版（1242 × 1660 px），配色延续网站的深蓝与金色。界面截图来自实际游戏画面，外围浏览器栏已裁掉。

## 轮播顺序

1. 身份揭晓：用身份牌做开场，抛出“你拿到身份后，会先找谁？”
2. 游戏大厅：展示可选桌游和开房入口。
3. 开局设置：突出缺人时可以添加 AI 玩家。
4. 对局桌面：展示座位、任务进度和发言顺序。
5. 发言与笔记：展示按轮次查看发言、记录自己的判断。
6. 队伍投票：展示公开提案与赞成/反对流程。
7. 角色图鉴：以角色能力与阵营线索收尾，引导评论互动。
